6. Embedded-System Integration Architecture (Task E)

The testbench models a heterogeneous Hardware-in-the-Loop (HIL) workbench comprising:

  1. Host Controller: STMicroelectronics STM32H753VI (ARM Cortex-M7 @ 480 MHz, 3.3V logic) for supervisory control.
  2. DSP Co-Processor: AMD/Xilinx Artix-7 XC7A35T (1.8V bank I/O) for real-time sensor filtering.
  3. Debug Probe: Segger J-Link Ultra+ Emulator (JTAG IEEE 1149.1 / SWD).
  • Star Grounding: Decouples high-frequency FPGA return transient currents from sensitive MCU analog reference planes.
  • Level Shifting: High-speed bidirectional voltage translators (TI TXS0108E) protect the 1.8V FPGA I/O gates from 3.3V MCU signals.
  • Role of JTAG vs General Compute: JTAG is an IEEE 1149.1 synchronous TAP master probe intended for boundary-scan test, non-volatile flashing, and hardware breakpointing. It lacks autonomous arbitration, packet framing, and asynchronous DMA messaging required for peer-to-peer compute.
  • Fault Injection: Implements 10 Hz simulated telemetry streaming, packet timeout / CRC error injection, and automated link recovery via POST /api/hardware/recover.

7. Handwritten Backpropagation Derivation & Verification (Task F)

For single regression sample x = 1, target y = 2, network equations are defined by:

z = w·x + b,   h = tanh(z),   y_hat = v·h + c,   Loss J = 0.5 · (y_hat - y)²
Initial: w_0 = 0.5,   b_0 = 0.0,   v_0 = 1.0,   c_0 = 0.0,   Learning Rate: η = 0.1

Step 0: Forward Pass Numerical Evaluation

  • Linear pre-activation: z = (0.5)(1) + 0 = 0.50000000
  • Hidden activation: h = tanh(0.5) = (e^0.5 - e^-0.5)/(e^0.5 + e^-0.5) = 0.46211716
  • Output prediction: y_hat = (1.0)(0.46211716) + 0 = 0.46211716
  • Prediction residual error: e = y_hat - y = 0.46211716 - 2.0 = -1.53788284
  • Step 0 Loss: J = 0.5 * (-1.53788284)^2 = 1.18254182

Multivariable Chain-Rule Derivatives

  • Output Bias c: ∂J/∂c = (∂J/∂y_hat) · (∂y_hat/∂c) = (y_hat - y) · 1 = -1.53788284
  • Output Weight v: ∂J/∂v = (∂J/∂y_hat) · (∂y_hat/∂v) = (y_hat - y) · h = (-1.53788284)(0.46211716) = -0.71068205
  • Hidden Unit Sensitivity: ∂J/∂h = (∂J/∂y_hat) · v = (-1.53788284)(1.0) = -1.53788284
  • Activation Derivative: dh/dz = 1 - tanh²(z) = 1 - (0.46211716)² = 0.78644773
  • Pre-activation Sensitivity: ∂J/∂z = (∂J/∂h)(dh/dz) = (-1.53788284)(0.78644773) = -1.20946448
  • Input Weight w: ∂J/∂w = (∂J/∂z) · x = (-1.20946448)(1) = -1.20946448
  • Input Bias b: ∂J/∂b = (∂J/∂z) · 1 = -1.20946448

Physical Explanation of Gradient Directions

Initial prediction y_hat_0 ≈ 0.462 significantly underpredicts target y = 2.0, producing a negative residual error (y_hat - y) = -1.538. Because activations v_0 = 1.0 > 0, h_0 ≈ 0.462 > 0, and (1 - h_0²) ≈ 0.786 > 0 are all strictly positive, every backward chain-rule gradient ∇J is strictly negative. Gradient descent updates in the opposite direction (-η∇J), adding positive increments to all four parameters. Increasing w, b, v, and c drives the prediction monotonically toward 2.0, causing the training loss to decay asymptotically from J_0 = 1.1825 to J_100 < 1e-6 over 100 iterations.
