Why JTAG is a Debug Interface, NOT a Generic Interchangeable Compute Board:
JTAG (IEEE Std 1149.1) is a synchronous, state-machine driven serial test and debug interface designed for Boundary-Scan Architecture and TAP controllers. The adapter acts as a synchronous bus master controlling dedicated signals (TCK, TMS, TDI) to drive the 16-state TAP finite state machine to access internal scan chains, On-Chip Emulation (CoreSight/ICE), and instruction registers. It does not execute application workloads, does not host an operating system, and cannot be treated as an interchangeable compute board on an application communication bus.

Mathematical Defense: Gradient Direction & Parameter Dynamics

At initialization, the model predicts y_hat = 0.4621, severely underpredicting the target y = 2.0 (error e = -1.5379). Because the loss gradient ∇J points in the direction of steepest increase in loss, each partial derivative (∂J/∂w, ∂J/∂b, ∂J/∂v, ∂J/∂c) is negative. Taking the negative gradient step θ ← θ - η·∇J results in positive increments to all four parameters, monotonically increasing the output prediction towards 2.0 and decaying the loss to zero.
